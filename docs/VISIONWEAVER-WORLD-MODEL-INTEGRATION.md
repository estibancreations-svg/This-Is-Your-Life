# This Is Your Life — VisionWeaver World Model Integration

**Date:** 2026-10-03

Future production should use VisionWeaver's persistent scene-world model for spatial, acoustic, lighting, environmental, and character continuity.

Scene generation/continuation should preserve:
- established chapel/location geometry
- character state and blocking
- props and set dressing
- light direction and exposure
- environmental sound sources
- visible and off-screen activity
- camera continuity
- temporal state
- causal reactions

The canonical engine remains in VisionWeaver. This project consumes that state rather than redefining it.
