## Design language recovered
- emotion is translated into environment, object, texture, memory and sensory description;
- recurring editorial/gallery format uses `THE FEELING`, `THE SENSES`, `REFLECTION`, `THE INVITATION`, `THE STORY IN DETAIL`, and `THE PAUSE`;
- environments and objects carry emotional evidence rather than functioning as decoration;
- this visual body is a primary reference for how the artist's work should communicate without conventional exposition.

## Assignment rule
These pieces are filed with Living Gallery because the originating visual-development conversation grew directly from the creator's description of an artist whose works transmit emotion. If a recovered original episode source assigns any piece elsewhere, the recovered source takes precedence and this manifest must be updated.
